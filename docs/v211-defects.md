# V2.1.1 剩余缺陷与验收限制

以下项目**未完成或未达到生产验收标准**，不得申请正式部署：

1. **共享工具 Schema 尚未完全消除重复**：`apps/sites/src/tools.js` 仍定义生产专属工具 Schema；共享名称已通过 `tool-protocol.ts` 统一，但重叠工具的 JSON Schema 仍有两份。下一步应把两份 Schema 合并为单一声明式注册表。
2. **生产 D1 checkpoint 恢复未接入**：真实增量 checkpoint 与哈希恢复已在 FsStore 契约测试通过，但 Sites Worker 仍使用生产 `save_checkpoint` 的完整快照路径，未接入 `restoreIncrementalCheckpoint`。
3. **分阶段故障注入不完整**：已验证幂等重复、进程重启后回执查询和真并发 CAS；尚未对事务各阶段做系统性故障注入。
4. **写入路径放大严重**：10,000 次真实合成 commit 耗时 53.8 分钟（3.1 commits/s），累计扫描约 98.5 GB；根因是每次提交重建/扫描整条世界线。100,000 次规模验收在当前实现下不可接受，必须先做 D1 增量写路径专项。
5. **SSE 表现层**：服务端可保证事务幂等与恢复，不能修复 ChatGPT 客户端自身 SSE 中断。
6. **正式迁移未执行**：没有访问生产 D1 或正式存档；迁移基准文件由私有备份生成，公共源码中没有硬编码常量。
7. **双世界线验证范围**：`memory.layers` 的世界线隔离已验证；完整生产 D1 两条世界线的权限/摘要/索引隔离仍需 Sites 适配环境验收。

因此本轮状态为：**阶段性成果通过静态审查，隔离 D1 链路部分闭环，但生产验收仍不通过**。
