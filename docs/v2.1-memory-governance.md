# V2.1 长程记忆治理专项（方案，未实施）

本文件是源码归一化完成后的专项计划。当前分支只交付共享内核、统一 MCP 协议与存储适配层；以下能力**尚未实现**，不得当作现状。

## 目标

在保持 Sites 生产兼容基线的前提下，把“长期保存”与“当前可用”分离：保留可追溯事实，控制召回噪声，显式处理失效、信念、私密与历史补录。

## 治理对象

- 实体与关系：`validFrom` / `validUntil`、`status`、`supersedes`、`knownBy`、`epistemic`、`holder`、`confidence`。
- 情景：`at`、`turn`、`sourceEventId`、`tags`、原文路径，历史补录必须标记 `historical-backfill`。
- 人格记忆：独立世界线 `wl-noa-persistent`，不吸收世界专属授权。
- 资源记录：不可变原始证据与可修订派生摘要分离。

## 分层

1. **热层**：当前世界线、当前视角可见、未失效、高置信度事实；用于常规召回。
2. **温层**：仍有效但低置信度、长尾或低访问频率；按需召回，不进入默认冷启动。
3. **冷层**：已失效或被 `supersedes` 替代的关系、历史补录、旧情景；只按 `asOf` 或审计请求读取。
4. **不可变层**：原始证据资产、迁移哈希、回执与审计；永不自动删除或改写。

## 治理动作（待实现）

- 时间有效性：查询必须同时应用世界线、`asOf`、`knownBy`、`epistemic/holder`；禁止用最新状态覆盖历史事实。
- 冲突裁决：同主题多版本必须显式 `resolution`，保留 `supersedes` 链和裁决理由。
- 整合：只合并来源事件可追溯、holder 与可见性一致的重复关系；不丢弃原文。
- 衰减：影响召回排序，不改变事实真值；GM 可固定重要节点。
- 权限：GM 视角绕过 `knownBy` 仍受世界线与时间约束；私密原始证据不可被派生资产覆盖。
- 审计：每次治理动作生成可回放事件，包含 before/after 哈希与操作者。

## 验收

- 同一查询在 FS / SQLite / D1 适配层返回等价节点与边集合。
- 失效关系不会作为当前事实召回，但能在指定 `asOf` 下重现。
- 人格记忆不会跨世界线泄漏；世界专属授权不进入人格命名空间。
- 治理事件可导出、可在空库回放，回放后状态与记忆哈希一致。
- 10,000 commit 规模下冷启动与召回预算可测；未达标不得宣告完成。

## 顺序

源码归一化与跨平台契约测试合入后再开专项分支；不把记忆治理改动混入本次统一内核 PR。
