# LocalD1 兼容范围

## 支持

- `prepare(sql)`、`bind(...params)`
- `all()` / `first()` / `run()`
- `batch(statements)`：单事务执行，失败整体回滚，返回 `[]` 与 D1 批次结果一致
- `sql` 元数据：仅用于本地测试/诊断；生产 D1 不保证暴露，业务不得依赖

## 不支持

- 交互式跨请求事务
- D1 之外的连接池/游标
- 生产 D1 的物理限额模拟（仅 SQLite 行为）

## 失败语义

- 约束错误、SQL 错误原样抛出
- `batch` 中任一语句失败，之前的写入回滚
- 本地 Host 不利用 SQLite 更强事务能力绕过 D1 契约
